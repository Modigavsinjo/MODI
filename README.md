# Modi Gavsinjo
Security and Maintenance

The repository owner is responsible for maintaining the website content and protecting access to the repository and its publishing configuration.

Recommended safeguards include:

Enabling multifactor authentication or passkeys for GitHub access.

Restricting repository permissions to authorized individuals.

Protecting the production branch against unauthorized changes.

Reviewing and monitoring changes to published files and deployments.

Independently verifying any proposed change to the beneficiary name or IBAN before publication.

Periodically checking the live website to confirm that its content remains accurate.

These measures reduce risk but do not guarantee that the website, its hosting account, or the displayed payment information cannot be compromised.

Privacy

This project is intended to display business payment information. No personal, confidential, authentication, or other sensitive information should be committed to this public repository.

Any information published here should be reviewed to confirm that its disclosure is authorized and appropriate.
